# PR 02 — A focused, trustworthy participant journey

## Why

Pre-response hints about anchoring can prime answers, while v1 treats an opaque network request as a successful save. The new experience poses a neutral shopping question and reveals the manipulation only after the verified save acknowledgement.

## Changes

- Keep the premium mauve/cream visual style and identical bottle for both groups.
- Neutral first screen, clear fictional product and example listed price, no explanation of the two arms before responding.
- Post-submission comparison with both prices and a transparent limitation statement.
- Separate frontend into `assets/style.css` and `assets/app.js`.
- `config.js`: live Worker URL. With a missing configuration, v2 explicitly refuses live submissions instead of pretending to save.
- `?demo=1` permits both arms without contacting storage; `?demo=1&arm=high` previews the high arm.
- A prior confirmed response can be shown again after reload. Server keeps assignments and submissions idempotent.

## Deployment gate — DO THIS BEFORE MERGING

1. Deploy PR 01's Apps Script and Cloudflare Worker, verify `/api/health` through browser or test environment. API requires Origin header from your Pages domain; direct navigation gives 403 by design.
2. Replace `PASTE_YOUR_WORKER_URL_HERE` in `config.js` with your actual Worker origin, e.g. `https://framing-lab-api.xxxxx.workers.dev`.
3. Confirm Cloudflare `ALLOWED_ORIGIN` is the exact Pages origin `https://USERNAME.github.io` (not `/framing-lab/`).
4. Use `?demo=1` first, then try a real response in a private browser window, check `V2_Assignments` and `V2_Responses` in the existing Google Sheet.
5. The original v1 `Responses` tab is preserved. V2 data is **not merged** with v1.

## Acceptance

- Only one experimental price is visible pre-answer; reveals of both arms occur after confirmed storage.
- Network failure or missing Worker configuration never shows a false success.
- Retrying a valid response writes only once.
- Existing v1 data remains intact; regular v2 uses new v2 sheets.
