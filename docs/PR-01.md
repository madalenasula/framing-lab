# PR 01 — Data integrity and v2 collection

## Why

V1's `mode: no-cors` cannot read or validate the Google Apps Script reply and can claim completion without a stored record. It also accepts client-declared assignment and has no reliable dataset version separation.

## Scope

- Add a Google Apps Script collector preserving **v1** and isolating v2 in `V2_Assignments`, `V2_Responses`, `V2_Events`.
- Create server-side persisted 50/50 assignment, idempotent submit, server-resolved reference condition, pseudonymous funnel events.
- Add a Cloudflare Worker JSON/CORS bridge to give the frontend a readable backend acknowledgement.
- Add withheld aggregate results until study closed and >=20 per group. This gate is for privacy/interpretation, **not** power.
- Add automated backend/Worker tests and manual deployment instructions.

## Deployment order

1. Google Sheet > Extensions > Apps Script. Back up existing code, replace with `backend/Code.gs`.
2. Deploy > Manage deployments > edit existing Web app > **New version** > Deploy. Keep Execute as Me and access Anyone. The existing `/exec` URL should remain the same when updating the deployment.
3. Configure `wrangler.toml` `ALLOWED_ORIGIN` to the exact Pages origin (no `/framing-lab/`).
4. From project root, run `npx wrangler login`, then `npx wrangler secret put APPS_SCRIPT_URL` and paste the existing Google Apps Script `/exec` URL. Run `npx wrangler deploy`. Copy the assigned `https://...workers.dev` address.
5. You can leave v1 Pages live after this PR. v2 frontend is introduced by PR 02.

## Acceptance

- V1 submissions still go to `Responses`.
- V2 assign persists an assignment and reusing an ID returns the same condition.
- V2 submit saves once; retrying returns the stored answer.
- Invalid amount and missing assignment produce failure without saving.
- Visitor never sees success until the Worker reads `{ok:true,saved:true}` from Apps Script.

## Known limits

- Apps Script web app is publicly callable even though the browser site goes via Worker. Origin/CORS is not authentication. This is not bot-resistant production infrastructure.
- Google Apps Script ContentService redirects to `script.googleusercontent.com`. Worker must follow redirects.
- Do not collect names, emails, IPs, or other personal data. Google/Cloudflare still process service-level request metadata.
